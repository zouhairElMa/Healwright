# Support

## Documentation

Start with the [README](README.md) and the [documentation site](docs/index.md).

## Questions and bug reports

Use [GitHub Issues](https://github.com/zouhairElMa/Healwright/issues).

For a useful report, include:

- Healwright, Node.js, Playwright, Java, and PostgreSQL versions.
- The failing locator and a minimal reproduction.
- Whether `reportOnly` changes the behavior.
- Relevant dashboard output with secrets and personal data removed.

Do not open a public issue for security vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Maintenance

The latest stable release receives fixes. Compatibility with newer major Playwright or backend versions must be validated before it is claimed. No service-level agreement is currently provided.
